# Синхронизация с Google Диском

## Что приложение делает

* Складывает в ваш Google Диск один файл — `zakazano-backup.zip`. Это тот же самый архив,
  что получается по кнопке «Сохранить в файл»: `data.json` со всеми записями и папка
  с фотографиями. Копия с телефона и копия с Диска взаимозаменяемы.
* Файл **перезаписывается**, а не копится: на Диске всегда одна, самая свежая копия.
  История версий при этом остаётся в самом Диске («Управление версиями» у файла).
* Запрашивается ровно одна область доступа — `drive.file`. Она даёт приложению
  только его собственные файлы: ваши документы, фотографии и всё прочее на Диске
  приложению не видны в принципе.
* «Восстановить с Диска» **заменяет** содержимое приложения копией, как и обычный импорт.
* Автовыгрузка раз в сутки идёт в фоне и только при наличии сети.

Это резервное копирование, а не двусторонняя синхронизация: два телефона, которые правят
записи одновременно, не сольются. Для одного телефона (и для переезда на новый) этого хватает.

## Что нужно сделать один раз

Приложение не в Google Play, поэтому доступ к Диску оно получает через ваш собственный
проект в Google Cloud. Карту привязывать не нужно — всё используемое здесь бесплатно.

### 1. Проект

[console.cloud.google.com](https://console.cloud.google.com) → выбор проекта →
**New project** → название, например `Zakazano` → **Create**.

### 2. Включить Drive API

**APIs & Services → Library** → найти **Google Drive API** → **Enable**.

### 3. Экран согласия

**APIs & Services → OAuth consent screen** (в новой консоли — **Google Auth Platform**):

* тип — **External**;
* название приложения — «Заказано», почта поддержки и контактная — ваша;
* в разделе **Data access / Scopes** добавить `https://www.googleapis.com/auth/drive.file`
  (в списке помечена как **Non-sensitive**);
* в разделе **Audience** нажать **Publish app**.

Про «Publish app»: область `drive.file` несенситивная, поэтому проверка приложения
в Google для неё не нужна и страшного предупреждения при входе не будет. Если оставить
проект в состоянии *Testing*, доступ придётся подтверждать заново примерно раз в неделю.

Для этого проекта страницы уже опубликованы, домен подтверждён:

| Поле в Branding | Значение |
|---|---|
| Application home page | `https://doctorsnort.github.io/zakazano/` |
| Application privacy policy link | `https://doctorsnort.github.io/zakazano/privacy.html` |
| Authorized domains | `doctorsnort.github.io` |

Исходники страниц лежат в папке `site/` этого репозитория, а раздаются из
репозитория `DoctorSnort.github.io` (папка `zakazano/`). Правки нужно переносить
в оба места — автоматической связи между ними нет. В корне того репозитория лежит
личная страница: там же находится метка `google-site-verification`, и убирать её
нельзя, иначе Google снимет подтверждение домена.

### 4. OAuth-клиенты

**APIs & Services → Credentials → Create credentials → OAuth client ID → Application type: Android.**

Нужны два клиента — приложение, собранное для отладки, и обычное — это для Google
разные программы:

| Клиент | Package name | SHA-1 |
|---|---|---|
| Zakazano | `kz.chaykin.zakazano` | `5C:F3:CC:5F:B8:BF:82:CF:5A:81:D5:B5:2E:B6:B5:C1:43:E5:5E:82` |
| Zakazano debug | `kz.chaykin.zakazano.debug` | `65:B4:DE:FD:C1:A5:EE:A4:A5:85:5C:37:90:49:4D:3D:32:59:E5:B2` |

Если хватает только установленного APK — достаточно первой строки.

Никаких ключей и файлов в приложение прописывать не надо: Google узнаёт его
по имени пакета и отпечатку подписи. Поэтому же после смены ключа подписи
нужно будет добавить новый SHA-1.

Отпечаток release-ключа при необходимости берётся так:

```bash
keytool -list -v -keystore zakazano-release.jks -alias zakazano
```

### 5. Проверка на телефоне

**Настройки → Google Диск → Подключить Google Диск** → выбрать аккаунт → разрешить.
Дальше «Выгрузить сейчас» и, если нужно, включить «Выгружать раз в сутки».

## Если что-то пошло не так

| Сообщение | Что это значит |
|---|---|
| «Приложение не зарегистрировано в Google Cloud…» | В проекте нет OAuth-клиента с этим именем пакета и SHA-1. Чаще всего — забыли клиент для `.debug`-сборки |
| «Google Диск больше не пускает…» | Доступ отозван или истёк — нажать «Подключить Google Диск» ещё раз |
| «Нужно войти в Google-аккаунт на телефоне» | На устройстве нет ни одного аккаунта Google |
| «На Google Диске нет копии „Заказано“» | Выгрузка ещё ни разу не проходила, восстанавливать нечего |

Отключение в настройках приложения перестаёт пускать его к Диску, но сам выданный
доступ остаётся в аккаунте. Совсем отозвать его можно на странице
[Сторонние приложения с доступом к аккаунту](https://myaccount.google.com/permissions).
