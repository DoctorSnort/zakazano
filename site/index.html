Заказано

Личный справочник по заведениям и тому, что в них заказывали. Android.

Ходишь по кафе, пробуешь блюда, а через полгода возвращаешься и не помнишь ни что брал, ни было ли это вкусно. Приложение закрывает ровно это: заведение → блюда и напитки → оценка, цена, комментарий, фотографии.

Что умеет

  • Список заведений с поиском, сортировкой по алфавиту, оценке и свежести.
  • Внутри заведения — вкладки «Блюда» и «Напитки», листаются свайпом.
  • Оценка из четырёх ступеней: стрём · никак · неплохо · кайф. Никаких десятибалльных шкал — оценивать нужно за секунду.
  • Средний балл заведения считается сам по всем блюдам и напиткам.
  • Цена, комментарий, фотографии с камеры или из галереи.
  • Фильтр по оценкам и по виду напитка.
  • Светлая и тёмная тема.

Где хранятся записи

На телефоне. У приложения нет ни сервера, ни аккаунта, ни аналитики — оно работает полностью офлайн.

По желанию резервную копию можно складывать в ваш собственный Google Диск: это один ZIP-файл zakazano-backup.zip со всеми записями и фотографиями. Приложение запрашивает единственную область доступа drive.file — она позволяет работать только с теми файлами, которые приложение само создало. Остальное содержимое вашего Диска ему недоступно технически.
